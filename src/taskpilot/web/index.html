Deskhand

Welcome to Deskhand

Tell your computer what to do, by voice or text, from anywhere. It does the clicking and typing for you.

  • Works on your own computer, not in the cloud
  • Asks you first before anything risky
  • No password: we email you a sign-in link

Check your inbox. Tap the link in the email, or type the code from it here.

Connect this device

Sign-in by email is not switched on for this server yet. If you were given a code, enter it below. Otherwise ask whoever runs Deskhand to turn email sign-in on.

Enter the code shown on a device that is already set up (Settings, then Add a phone or computer), or an invite code you were sent. A code works once.

By signing in you agree to the terms. Read how your data is handled in the privacy policy.
